# Comparative study of federated adaptation strategies for remote-sensing change detection

Supporting materials for the manuscript by Tian Jiang, Hao Wang, Yu Shi, Yuxiang Li, and Xintao Fu, prepared for submission to the *Journal of Applied Remote Sensing*.

## Supporting materials

- [Online Resource 1 — supplementary information](supplementary/ESM_1.pdf): detailed model and input definitions, training settings, client construction, diagnostics, centralized reference, and numerical-resource guide (Sections S1–S6).
- [Online Resource 2 — numerical records](supplementary/ESM_2.zip): 16 CSV/JSON data files and administrative metadata. Download and extract the ZIP; see its README for the file inventory and field meanings.
- [File checksums](SHA256SUMS): SHA-256 checksums of the supporting files.

These resources are hosted by the authors. Their presence does not imply that the manuscript has been accepted or that the files are journal-hosted attachments.

## Implementation status

The implementation and associated release materials will be added to https://github.com/TianJiang204/Comparative-study-of-federated-adaptation-strategies-for-remote-sensing-change-detection in a future update.

The numerical archive does not contain the complete training implementation, raw imagery, model checkpoints, image-level predictions, or complete training histories. Public source-dataset links and the study's reproducibility boundaries are documented in Online Resource 1 and in the archive README.

## Version

Materials prepared on 28 November 2026. Scientific text, reported results, and all 16 numerical-resource data files are retained from the supplied submission materials; author contact information and access information have been updated.
